# モンスターの拡大表示（2026-10-04）

## 変更

- 図鑑とトップページの「次の敵」の絵をクリック・タップすると、名前と大きな絵を表示。
- 画面幅・高さに応じて余白を確保。絵は最大640 CSS px、画面高さの62%以内。ダイアログは幅760px、画面高さの90%以内。
- 端末のピクセル密度も考慮し、表示に必要な実ピクセルが元画像の1024pxを超えないように上限を設定。
- 画像版と従来のSVG版の両方に対応。
- 図鑑の未撃破キャラは名前を「???」、絵を暗いシルエット表示のまま拡大。
- ×、画面外、Escで閉じる。閉じた後にクリック元へフォーカスを戻し、ページのスクロールも戻す。
- 元の生成PNGから1024pxの透過WebPを43体分作成。画像内容は縮小のみで書き出し、元画像の引き伸ばしは行わない。
- 1024px版はクリックした1体だけ取得。通常の戦闘・トップ・図鑑は従来の256/384px版を使用し、高解像度版の先読みはしない。
- 高解像度版は43体合計6,949,824 bytes、平均約158 KiB、最大約246 KiB。合計値は配布ファイル量であり、画面表示時に全体を取得する量ではない。
- 開く時にクリック位置から240msで拡大・フェードするCSSアニメーションを追加。transformとopacityを使い、終了後は変形を残さない。新しいライブラリ・常時アニメーションは追加しない。
- 「動きを減らす」端末設定ではアニメーションを停止。ダイアログ・端末解像度の変更監視は、開いている間だけ有効。

## 確認

- テスト専用Chromeで英検5級Level1（WebP）と英検4級Level3（SVG）を確認。
- 1366×800・390×800に加え、1920×1080/DPR2、390×640/DPR3/動きを減らす、844×390の横長画面を確認。
- PCトップの開閉、図鑑43個のクリック対象、取得済みと未撃破キャラ、×・画面外・Esc、画像クリックでは閉じないことを確認。
- スクロール復帰、フォーカス復帰、横はみ出しなし、撃破記録の維持、実行時エラー0を確認。
- クリック前の1024px取得0、開いた1体だけの取得、同じ絵の再表示時に別の画像を取得しないことを確認。SVGは追加画像取得なし。
- PCで以前の320pxより大きい表示、画面内の余白、元画像の解像度以内、アニメーション終了後の変形なし、動きを減らす設定を確認。
- スマホ実機のタップ・通信・体感性能は未測定。390px幅はブラウザによる画面サイズ確認。
- `scripts/test-monster-preview-ui.mjs` に確認手順を保存。

制作中のLevel2・3の新しい画像は、この拡大機能の公開には含めない。
