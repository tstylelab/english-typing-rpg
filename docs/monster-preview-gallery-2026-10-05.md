# モンスター拡大表示：展示室の背景と名前の装飾

- 名前を端末内の明朝体、太字、アイボリー寄りの金色、控えめな影に変更。長い名前は画面内で折り返す。外部Webフォントの取得なし。端末により使われるフォントは異なる。
- built-in image_genでぼかし済みの空の幻想的な展示室を新規生成。640×640px、6,272バイトの共通WebPを低い不透明度で使用。原PNGはdesign/monster-samples/preview-gallery/original-background.pngに保全。
- キャラの背後に淡い静止グラデーションの光だまりを置いた。表示中のfilter/backdrop-filter、常時アニメーション、追加ライブラリなし。
- 背景は拡大dialogが開いたときだけ取得。図鑑・トップの通常表示や入力画面への背景追加は今回の対象外。
- キャラ画像の1024px上限と端末DPRによる表示サイズ制限、開く動き、矢印・キー・模擬左右スワイプ、ロック表示、撃破記録、閉じた後のフォーカス復元を維持。

## 確認

英検4級Level1/3のPC1366px・スマホ390px、英会話SVG、英検5級の高DPR・横長画面を含む9条件で既存の拡大UI検査を通過。背景が開く前に取得されないことと、表示中のぼかし処理がないことも検査。PC・スマホ幅のスクリーンショットで背景と文字を目視確認。

ビルド成功。lintはエラー0、既存Hook警告1。既存の大きなbundle警告は残る。実機タブレットの体感速度・指操作は未測定。
