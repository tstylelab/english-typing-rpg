# 英検 Level 2・3 バトルの数値調整（ローカル・2026-10-16）

## 対象と方針

本人から、5級L2/L3の水準を全級へ適用し、文字数差も考慮して数値で調整する依頼。比較元は公開済み `ce88ad99560f3bf48df0d10dd5fe942102edcdae`。

- 英検9教材（分冊含む）×L2/L3×和訳/音声×23段階＝828設定。
- 5級の既存HP曲線と問題数を基準にする。序盤から通常後半、ラスボス、裏ボス3段階まで対象。
- 長文ほど攻撃力が無制限に上がる仕組みを完成点へ変更し、文字数に対するミス割合で減点。
- 正確で遅い入力でも全段階を倒せる。小さなミスを許容し、多数ミスを速度で打ち消せないようにする。
- 長文教材の一戦が長くなりすぎないよう、収録問題の平均文字数から問題数とHPを同率で補正する。
- L1、練習2方式、苦手復習、英会話、対戦モードは変更対象外。学習状態の判定、撃破済みID、再挑戦位置、保存処理は変更しない。

5級の旧ダメージをそのまま複製したわけではない。旧設定にも「遅い正確入力では届かない」「速ければ多数ミスでも勝てる」組み合わせがあるため、5級の段階構成を基準にダメージも全級共通で調整した。

## 計算式

`L`＝完成した回答の文字数（空白・記号を含む）、`M`＝その回答中のミス数、`v`＝入力速度（文字/秒）。

```
ミス率 r = M / max(1, L)
速度加点 b = min(0.1, max(0, (v - 1) / 30)) × max(0, 1 - 4r)
完成点 C = Level 2: 225 / Level 3: 200
ダメージ D = floor(C × max(0.2, 1 - r) × (1 + b))
```

- 1文字/秒以下でも速度減点なし。4文字/秒以上でも最大10%の加点。
- ミス率25%以上は速度加点0。全文字分ミスしてから完成しても45/40ダメージにとどまり、どの相手も制限内では倒せない。
- 10文字で1ミスと40文字で4ミスは同じ減点。長い回答への許容ミス数は比例して増える。
- 音声ヒント使用時は速度加点をなくした上でダメージ半減（既存ルール）。スキップや学習記録処理は維持。
- ミス率は理解度・正答率そのものではない。「1問に1回の打ち間違い」と「答えが分からず何度も間違える」を区別している。

### 完成点の根拠

5級L2音声の最も厳しい通常段階は `1602 HP / 8問 = 200.25` ダメージ/問が必要。完成点225なら10%ミス時も `floor(225×0.9)=202` で届く。L3は既存の完成点200を維持し、10%ミス時180で全段階に届く。和訳は既存のHP8%軽減を基準にする。

## 通常モンスターも段階的に強くする

全級L2和訳の例。毎問10文字、毎秒1文字、音声ヒントなし。数値は「必要問数 / 上限」。毎回同じミス数で完成する条件。

|---|---:|---:|---:|---:|
|1体目|850|4 / 8|5 / 8|6 / 8|
|10体目|1400|7 / 8|7 / 8|9 / 8：届かない|
|19体目|1474|7 / 8|8 / 8|10 / 8：届かない|
|ラスボス|2210|10 / 12|11 / 12|15 / 12：届かない|
|裏ボス最終|3684|17 / 20|19 / 20|24 / 20：届かない|

L2の平均文字数は全教材で9.19〜11.65文字。後述の補正を計算しても切り上げ後の問題数は同じになり、全級が上表のHP・問題数になる。

5級L3和訳は、ミス率10%で180点/問の場合、通常1体目4/6問、10体目5/6問、19体目6/6問、ラスボス9/10問、裏ボス最終14/16問。ミス率30%なら19体目7/6問、ラスボス11/10問、裏ボス最終18/16問で届かない。

## 長文の入力負担の補正

収録全文を集計する（個人の苦手・復習対象には依存しない）。

```
短縮率 = min(1, sqrt(5級の平均文字数 / 対象教材の平均文字数))
問題上限 = ceil(5級の同じ段階の問題上限 × 短縮率)
           ただし通常は最低4問、ボスは最低8問
HP = round(5級の同じ方式・段階のHP × 新問題上限 / 5級の問題上限)
```

HP/問題数をほぼ一定（整数丸め差だけ）に保つので、必要な入力精度を下げずに戦闘時間を短縮する。平方根は、文章が長くなる負担を部分的に吸収しつつ、1〜2問で終わる戦闘を避ける設計上の選択。級名ではなく実際の平均文字数で決める。

|Level 3教材|平均文字数|通常上限|ラスボス上限|裏ボス最終上限|裏ボス最終HP（和訳）|
|---|---:|---:|---:|---:|---:|
|5級|18.52|6|10|16|2466|
|4級|27.95|5|9|14|2158|
|3級|25.93|6|9|14|2158|
|準2級|33.09|5|8|12|1850|
|2級|41.13|5|8|11|1695|
|準1級①|27.65|5|9|14|2158|
|準1級②|28.61|5|9|13|2004|
|1級①|53.67|4|8|10|1541|
|1級②|56.88|4|8|10|1541|

例えば2級L3の裏ボス最終は、ミス率10%で14問相当から10問相当へ短縮。平均文字数で見た入力量は約576文字から411文字へ。1級②は約796文字から512文字へ。これは平均文字数×必要問数による目安であり、実際の出題順・読解時間・音声時間まで同一にはならない。
