# 英検 Level 2・3 バトル強度の調査

## 依頼と範囲

準2級Level 2の和訳バトルが弱すぎるとの申告。その後、他級Level 2/3も対象に拡大。今回の変更は調査スクリプトと記録のみ。ゲームのHP・採点・保存データは変更していない。

## 確認結果

- 本体の `getBattleTuning` と `handleCorrectAnswer` 内の計算をVMで実行。全9教材（5級〜1級①②）、Level 2/3、和訳/音声、全23体、入力速度1/2/4.4文字毎秒、ミス0/毎問1/文字数30%切上げ/文字数と同数の条件を比較した。
- UI統合前 `d81971d` と現在のHP設定・1,390,488件の回答ダメージが一致。今回のUI変更によりモンスターが弱くなったわけではない。
- Level 2はミス減点の下限が通常ダメージの75%。文字数の25%以上間違えても、それ以上ダメージは減らない。通常の速度倍率は最大3倍で、速く直せばミスの多さを補えてしまう。
- Level 2のHPには問題数短縮に比例した調整に加え0.88倍、和訳はさらに0.92倍が適用される。これらはいずれも以前からの設定であり、再開時に繰り返し掛かるものではない。
- 具体例：準2級Level 2和訳の1体目はHP777・最大8問。10文字を毎秒2文字で完成すると無ミス180点、10ミスしても135点。後者を6問完成すると810点となり撃破できる。これは「誤答のまま進む」意味ではなく、間違えたあと修正して正しい文字列を完成させるケース。
- Level 3は完成200点を基準に文字数に対するミス率で減点し、速度補正は最大1.3倍。Level 2の75%下限とは別。全問1ミスでは勝てる設計で、30%の文字数相当を毎問ミスしても、速ければ勝てる範囲が広い。これは過去の全文完成・長文のミス許容方針に由来する。
- 逆方向の注意：準2級L2・通常19体目は、毎秒1文字・無ミスでもランダムな短い表現が続くと8問で届かない。HPを一律に上げるだけでは、ゆっくり正確に入力する人をさらに不利にする。
- 撃破と学習状態の判定は別。長文の学習判定は英字数を基準に約25%（短い語は最低3回）のミスを許容し、書式だけのミスを差し引く。ゲームの勝敗だけから習得判定の挙動を推測してはならない。

## 決定的な診断用シミュレーション

各条件で全教材問題から200回、固定seedで均等抽選。実際のユーザーの苦手・復習・手動絞り込み・入力開始前の思考時間は含まない。したがって実ユーザーの勝率ではない。
