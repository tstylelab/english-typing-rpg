# 5級・初心者の理解に必要な土台の点検

## 判断の順番

既存問題を説明するためだけの一覧にはしない。英語を初めて学ぶ子が理解に必要とする内容を先に整理し、解説を用意した上で、練習が不足する部分に問題を足す。既存問題で十分練習できる項目は重複追加しない。

英検公式の「中学初級程度・初歩的な英語」という位置付けを確認。以下はアプリの学習設計上の点検であり、公式の全出題項目や合格保証ではない。

## 点検と対応

|理解に必要なこと|説明の対応|練習問題の対応|
|---|---|---|
|I / you / he / she / it / we / they がだれ・何を指すか|先頭に主役の言葉カードを追加|既存に加え We are students. / They are teachers.|
|名詞・動詞・主語とは何か|用語を知っている前提にせず専用カードを追加|既存 I have a book. を専用カードへリンク|
|am / is / are は何をする言葉か|既存beカードを初心者向けに書き直し、意味と組み合わせを表示|既存の I am / You are / He is などを維持|
|日本語と英語の語順の違い|I / like / music. を役割ラベル付きで色分け。全ての文が3要素とは限らないことも説明|既存 I like music. / I play tennis. を語順カードへ|
|単語の間の空白、大文字、文末の記号|語順カードで明示。IamとI amは別だと説明|既存・追加の文全体で扱う。採点方式自体は変更しない|
|This / That、These / Those の距離・数の違い|専用カードを追加|既存2文等に加え複数・疑問・否定の4問|
|I'm / You're の意味とアポストロフィ|短縮形カードを追加。完全形も正しいがゲームは指定形入力と明示|2問追加、和訳に短縮形の指定|
|1つと複数、a / an / the|単複カードを独立した学習内容に書き直す。冠詞カードは既存を使用|既存 a book / two dogs / an egg / the egg / children 等を活用|
|所有・目的語の代名詞|既存 my / me / mine のカードを維持、主役の代名詞の後に学べる位置|前回追加済み mine / hers / him / us / them 等を使用|
|数えられる物・水などの量、some / any|独立カード追加。質問にsomeを使う例外も補足|any の否定・疑問2問追加、some waterは既存|
|肯定・否定・疑問、短い返事|既存説明を維持し、Yes / No の返事カードを追加|be / does / can の肯定・否定6問。和訳には質問の状況を付記|
|年齢・時刻を尋ねた後にどう答えるか|既存wh/天気時刻カードを補強|年齢・時刻の答え2問追加|
|一般動詞・三単現、形容詞/副詞、前置詞、接続詞|既存の型と例を確認して維持|既存問題を活用|
|can、命令、誘い、現在進行形|既存の説明と練習を維持|既存問題を活用|
|過去・未来・不定詞など|従来収録の発展表現として区別|今回の不足補強を理由に難しい範囲を追加しない|

- 223→241問（18問追加）、25→32カード（7枚追加）。公開済み223問の順序・本文・和訳は変更せず、Level1/2や他級・戦闘バランスを変更しない。
- 既存カードIDは保持。保存したカードが消えない。結果のリンクは241問すべて明示対応。
- 教材テストで公開commit 902de4cの223問を比較、重複/文字種/長さ/対応先/先頭の学習順を検証。
- 無音・隔離Chromeで1366/390/320px。短縮形・複数形・短い返事の実入力→結果→対応解説をそれぞれ検証。保存・再読込・焦点/スクロール復帰・学習データ非変更も検証。
