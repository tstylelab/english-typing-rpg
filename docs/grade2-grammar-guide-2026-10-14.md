## 解説で区別したこと

| 対比 | 説明するポイント |
| --- | --- |
| because / because of | 理由の文を続けるか、名詞のまとまりを続けるか |
| This is because / That is why | 後ろが理由か、結果・判断か |
| the idea that / the book that | 名詞の内容を示す節か、目的語の抜けた関係節か |
| know where the bus stops / how to apply | 疑問詞＋主語＋動詞か、疑問詞＋to＋原形か |
| to study / The important thing is to … | 目的を添えるか、重要なことの中身を示すか |
| worth trying / worthwhile to try | 意味が近くても後続する形が違う |
| The number of / A number of | 数そのものか、複数の人・ものか |
| however / although / while | 文と文の関係、接続の仕方、時間と対比の違い |

各カードに具体的な英語見出し、日本語の学習内容、型、和訳付き例文2つ、要点、折りたたみの補足を用意。必要なカードには比較表と文の区切りを追加。すべての補足を常時展開しない。

本一覧はこのゲームの収録文を理解するための教材で、英検公式の文法範囲や2級全範囲の網羅を示すものではない。現在完了などの基礎は3級へのリンクからも確認できる。
