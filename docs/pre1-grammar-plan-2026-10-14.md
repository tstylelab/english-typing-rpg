## 章立ての案

1. **相手の話を理解する・確認する**：疑問詞節、what節、主語を尋ねる疑問文、Could you …、make＋人＋原形、Let me …。
2. **意見の強さ・同意の範囲を調整する**：not always / not entirely、not necessarily、would / might / could、would rather、tend to / inclined to。
3. **文の形と会話の省略を見分ける**：過去完了、助動詞＋have＋過去分詞、進行形、being、関係詞省略、前置きの断片、定型表現。

文法用語だけの見出しにせず、「must have been／過去の出来事を推量」のように具体的な形と短い学習内容を併記する。各級の結果からその級のカードに移動できるよう、保存キーとAI質問の対象級も分ける。

## 特に注意して説明する文

| 収録文 | 誤解を避けるための説明 |
| --- | --- |
| If I understand you correctly. | if節の前置き。後ろに確認内容の主節を続けた完全な例も示す。 |
| To put it simply. / To put it another way. | 説明を導く前置き。後ろに伝える内容が必要。 |
| When you put it that way. | when節の断片。会話で反応が省略される場合と、完全な文を区別。 |
| If you ask me. / The way I see it. | 意見を導く前置きであり、単独の標準的な完全文として教えない。 |
| Sounds about right. | That / Itの省略。「英語では主語を自由に省略できる」と一般化しない。 |
| That must have been difficult. | 過去への強い推量。「しなければならなかった」という義務ではない。 |
| I wouldn't be surprised if that were true. | 現在・未来を仮定する過去形。過去の事実を述べるwereとは区別。 |
| That doesn't necessarily mean it's wrong. | 必ずそうなるとは限らない、という否定の範囲。 |
| I can see where you're coming from. | 物理的な出身地ではなく、相手の立場・背景を理解する表現。 |
| I can see that happening. | ここではそうなる場面を想像できる意味。see＋目的語＋ingも示す。 |
| I'm just being realistic. | その場での態度・振る舞いを表すbeing。beは常に進行形にできない、という誤った断言を避ける。 |
