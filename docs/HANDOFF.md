## 2026-08-31 Androidタブレットの英語入力開始を改善

- 当初試したパスワード形式は、Pixel TabletのChromeで翻訳確認とパスワード保存確認が表示されたため、直ちに撤回した。
- `email` 向け入力設定もPixel 9aの画面キーボード入力を妨げたため撤回し、Pixel 9aで利用できていた通常の文字入力設定へ戻した。
- Pixel 9aはスマートフォン単体の画面キーボード、Pixel TabletはUSBキーボード接続で利用する前提を明確に分ける。
- 通常バトルと20問バトルに、端末ごとに保存される「外付けキーボード」切替を追加した。初期値は必ずOFF。
- OFFでは特殊な指定を使わない通常の文字入力欄とし、Pixel 9aなどの画面キーボードへ影響させない。
- Pixel Tabletで一度ONにすると、その端末だけ `inputmode=none` にし、入力欄のフォーカスを保ったまま既存の `KeyboardEvent.code` による物理英字キー取得を使う。
- 20問バトルの入力文字は、通常の文字入力欄で従来どおり直接確認できる。
- 「もう一度聞く」は、ON/OFFどちらでも入力欄へフォーカスを戻す。
- 前回のON設定で入力欄を読み取り専用にしてフォーカスを外したところ、Pixel TabletのAndroid Chromeでは物理キーイベントの入力先が失われ、入力できなくなった。PC Chromeだけの確認では検出できなかった端末差だった。
- ONでも入力欄は通常の `type=text` と編集可能状態を維持し、`inputmode=none` だけで画面キーボードを抑える。物理キーの配送先を確保するため、ゲーム開始・問題切替・再生後もフォーカスを維持する。
- ページ本体は日本語UIなので、文書言語を `lang=ja` に修正し、ゲーム内の日本語・英語教材をChromeに自動翻訳させないため `translate=no` を指定した。
- ローカルChromeで、通常バトルのON時に `type=text`・編集可能・`inputmode=none`・フォーカス中となり、`m`、再生ボタン後の `o` が入力されることを確認した。
- 20問バトルでも同条件でフォーカスが維持され、物理キー `g` が入力されることを確認した。
- OFFへ戻すと通常入力欄が再び選択されること、ON設定が同じ端末の再読み込み後も保持されることを確認した。
- Pixel TabletとPixel 9aの実機確認は、GitHubへpushして本番反映後に行う。
