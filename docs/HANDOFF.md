## 2026-08-19に行ったこと

### 英検4級の問題データ調整

- Level 1: 441問。重複していた `o'clock` を1件削除し、`sir` の日本語訳を明確化。
- Level 2: 200問を維持。抽象的・不自然だった表現を、実際に使える熟語・表現へ置き換え。
- Level 3: 200問を維持。英検3級寄りだった現在完了・関係代名詞・複雑な間接疑問文を、英検4級向けの過去形・直接的な5W1Hなどへ置き換え。

### Level 3の文法ポイント

- 英検4級Level 3の200問すべてに、最も重要な文法ポイントを1つ表示する仕組みを追加。
- 入力前には表示せず、答えた後の「前の問題」欄にだけ表示する。
- バトル終了画面では、「今回の問題と結果」の各問題に表示する。
- 表示内容は「文法の種類」「短い説明」「型」の3点。
- 5W1H、過去形、過去進行形、未来、比較、不定詞、動名詞、助動詞、命令文、会話表現などを英文に応じて出し分ける。
- 英検5級、英検準1級、Level 1・2には表示しない。

## 重要な設計判断

- このゲームは、過去問を始める前の単語帳・熟語帳と、基本文法の反復・定着を担当する。
- 最終的な試験形式への対応は、公式過去問や過去問集で仕上げる前提。
- 文法説明はゲームのテンポを崩さないよう、一問につき1点だけにする。
- 文法ポイントは答えを入力する前には見せない。
- 問題数はLevel 1が441、Level 2・3が各200のまま維持する。
- 5級と4級で重複する基礎語は、復習として価値があるため残す。

## デスクトップPCで再開するとき

1. デスクトップPCのCodexで、このリポジトリのフォルダを開く。
2. ターミナルで `git status --short` を実行し、デスクトップ側に未保存の変更がないか確認する。
3. 問題がなければ `git pull origin main` を実行する。
4. 必要なら `npm install` を実行する。
5. `npm run dev` を実行し、表示されたローカルURLを開く。
6. 英検4級Level 3をプレイし、解答後と終了画面の文法ポイントを目視確認する。
