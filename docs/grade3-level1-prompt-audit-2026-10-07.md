# 英検3級 Level 1：和訳バトルの出題点検（2026-10-07）

現行514語すべての表示用和訳・例文・想起しやすい別解を点検した。和訳を247語修正し、514語すべてに和訳バトル専用の「指定の単語」の手掛かりを付ける。

## 方針

- 訳は例文で使う品詞・意味に合わせ、異なる意味を羅列していた箇所を絞る。これがその語の全意味ではない。
- 同義語の意味に架空の差を付けない。smart/clever、fix/repair、afraid/scaredなどは日本語だけでは一意にならないので、和訳の下に頭文字・文字数を別表示する。
- everybody/everyoneは頭文字と9文字だけでも区別できないため、everyb…まで指定。複数語は各語の頭文字・語数を示す。文字数は空白を除き、ハイフンを含む。
- 正解の単語そのものは出題時に表示しない。別解を誤った英語だとは説明しない。自然な英訳すべてを受け付ける採点には変更していない。
- 表示と和訳の読み上げだけを更新。頭文字などの指定は日本語読み上げに混ぜない。英検3級Level 1以外、英語・例文・順序・問題数・元translation・保存キー・HP・採点は維持する。
- 514語の全辞書項目を一つずつ照合したものではない。意味の重なりは指定で補い、無理なニュアンス差で一意化したとは主張しない。
