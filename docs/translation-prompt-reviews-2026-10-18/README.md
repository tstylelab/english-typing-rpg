## 方針と限界

- 頭文字・文字数・正解の語を指定する手掛かりを追加しません。
- 短い自然な日本語、語義・動作と状態・品詞・構文の違いで補います。
- 本当に意味が重なる英語は比較情報として示し、架空の使い分けで一意に絞りません。
- 語の意味を例文の場面だけに限定しません。不要な補足は追加しません。
- 類義語の提示は、別解を追加で正解にする機能ではありません。自然な日本語だけで想定英文を完全に一意にできない問題は残ります。
- 元の問題英語・元の和訳・例文・順序は変更しません。保存キー・採点・HP・進行・ユーザーデータ処理は既存のままです。
