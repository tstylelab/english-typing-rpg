# 1日の解答数に応じた書き出し案内

## 動作

- 既存の「今日の解答数」が **201問以上** のとき、通常バトルの結果画面で案内する。勝敗や級・Level・出題方法は問わない。スキップは解答数に含めない。
- 結果表示から2.2秒待ち、撃破モンスターのCLEAR演出が残っていれば、終了まで待つ。戦闘中・ホーム・教材選択・アプリ起動時には出さない。結果から移動したら待機を解除する。
- 「データを書き出す」で既存のJSON形式（formatVersion 3）のダウンロードを開始する。現在のプレイヤーのみで、今回の撃破・学習状態・日別記録・各設定も含む。
- 「今日はあとで」またはEscapeで閉じる。そのプレイヤーには同じ日に再表示しない。日付は既存集計と同じ日本時間。
- 設定画面から201問以上の状態で書き出した場合も、その日は案内しない。
- エラー時は閉じず、再試行できる。ダウンロードの開始は確認できるが、利用者が保存を取り消したか、端末上でファイルを保管したかはブラウザーから判定できない。

## 保存と負荷

- 案内済みの日付は `etyping_backup_reminder:<playerId>` に保存する。端末・プレイヤー別のUI状態であり、学習データの書き出し・読み込みには含めない。他端末ではその端末の案内状態で判定する。
- 画像、追加ライブラリ、常時ポーリングなし。対象となる結果画面でだけ短いタイマーを使用し、必要なら演出DOMの削除を一時的に監視する。画面を離れると両方を破棄する。
- モーダル表示中は背景操作を無効にし、Tabを案内内に留める。閉じたら元のフォーカスに戻す。

## 検証

`scripts/test-backup-reminder-ui.mjs` をChrome / Playwrightで実行。

- 200問では出ない、201問では出る、スキップを除外
- 戦闘中には出ない、結果画面から離れれば待機を中止
- 390pxスマホ幅と1366pxPC幅、フォーカス移動・Escape
- 再読み込み後・同日2回目は再表示しない、翌日は再表示
- 共有端末での別プレイヤー判定、設定画面からの書き出し済み判定
- 通常のCLEARと、終了を遅らせたCLEARの後に案内
- 模擬エラーと再試行、実際にダウンロードしたJSONの形式・直前の撃破記録・設定

実機Android/Pixel Tabletでのダウンロード先・保存操作は未確認。
