# 文法カードからAIに質問

- 対象：5級32枚・4級33枚。カード末尾の折りたたみ内に「質問文をコピー」「コピーしてChatGPTを開く」「コピーしてGeminiを開く」と質問文プレビュー。
- 質問文：級・そのカードの表現/型/例文/要点/比較/補足のみ。結果から開いたカードには当該英文を添える。プレイヤー名・成績・履歴・ブックマークは含まない。
- 要望：初心者にも分かる丁寧な日本語、使う場面、短い例と和訳1〜2組、語順/役割、必要な違い。最初は400字程度、確認問題1問は回答待ち。原文に誤りがあれば訂正を促す。実AI回答の品質は未検証・保証しない。
- 質問生成はクリック時のみ、折りたたみを開くだけでは生成しない。履歴集計・保存・API通信なし。コピーが成功してから固定URLをnoopener/noreferrerで開く。URLに質問文を含めない。自動貼付・送信・回答取得なし。
- クリップボード失敗時：質問文を選択して手動コピー。ポップアップが開かなければ再オープンリンク。閉じた後に待機中のコピーが完了しても新規タブを出さない。
- 公式情報を確認：OpenAI利用規約 https://openai.com/policies/terms-of-use/ 、年齢案内 https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages 、Google利用規約 https://policies.google.com/terms?hl=ja 、Gemini条件 https://support.google.com/gemini/answer/13278668?hl=ja 。
- 通常の外部リンクと利用者の手動入力として設計。公式提携/特別な許諾/法的適合の保証を表示しない。ChatGPTは13歳以上、18歳未満は保護者の許可、13歳未満向け教育では大人が操作。Geminiは年齢/アカウント/地域の条件を確認する案内。AI誤答注意も表示。
- 検証：65カードの質問文テスト、4/5級教材テスト、ビルド、lint（既存warning1）。無音の隔離Chrome1366/390/320pxでコピー・プレビュー・外部URL（スタブ）・コピー拒否・手動コピー表示・閉じた後の遅延完了・保存非変更。既存の4/5級実入力→結果→解説・保存・復帰の回帰も成功。スマホ幅を目視。実際のAIサービスへ質問送信はせず、iOS/Android実機も未確認。
- 今回は実装のみ。commit/pushは未実施。

## 注意書きの省スペース化

- 本人が懸念したのは外部リンク設置の可否であり、長い注意書きの常時表示ではない。操作説明を短縮し、最下部に小さく「AIは誤ることがあります・利用条件」の1行。年齢条件と公式リンクは開いたときだけ表示する。
- 内側の利用条件の開閉で外側のAI操作欄が消えないようtoggleの対象を区別。5/4級、1366/390/320pxで開閉・コピー・代替表示・保存不変を再確認、build成功。質問文や外部リンク動作は変更なし。

## 説明対象を年齢ではなく学習級へ

- 「小学生にも分かる」を削除し、対象を「英検○級に挑戦する学習者」と明示。年齢・学年は決めつけない。説明の深さ・例文の語彙・確認問題は級とカード内容に合わせ、日本語は平易、文法用語には短い意味、必要な前提は補足する。簡単な文章と学習内容の難度を区別し、幼い説明や必要事項の省略を避ける。
- 5級・4級共通で反映。今後上位級カードを実装した際も指定級を使用する生成関数であり、今回3級以上のカード追加はしていない。
