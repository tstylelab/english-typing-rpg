# 未登録の類義語・言い換えの追加（2026-09-25）

## 方針

- 空欄を埋めることではなく、出題されている意味をつかむ助けになることを優先。
- 近い意味の語、自然な短い言い換えを選ぶ。単なる同じ分野の語・上位分類の語は新規追加の穴埋めに使わない。
- 単語が同じでもコース・Level・元の和訳が異なれば別の項目として扱う。
- 多義語の全語義に共通する完全な置換語とは限らない。表示和訳に含まれる意味で使える補助語。例文の中でそのまま置換できると保証しない。
- 一つの項目につき1〜3個、各24文字以内という既存の表示量を維持。適切な候補がない場合は非表示のまま。
- protein や hydrogen に、単なる上位分類を類義語として追加しない。複雑な熟語を誤った短文に縮めてまで件数を増やさない。
- 既存の5級・4級・準1級の「類義/関連」は上書きせず、今回の追加は未登録分のみ。既存の関連語全件の再監修は今回の対象外。
- Level 3（文章）の類義語を表示しない既存仕様は維持。

## 実装・互換性

- 新しい補助JSONを初回にMapへ索引化。繰り返し表示は既存キャッシュを利用し、画面更新ごとの全データ走査やネット通信を追加しない。
- 検索キーと結果キャッシュに元の和訳を含める。既存の question.synonyms 明示指定を最優先する挙動は維持。
- 全7,392問の原文・元和訳・例文・順序・保存キーは変更なし。入力判定、HP、音声処理、習得判定も変更なし。
- 回答後の復習欄と単語リストなど、既存の共通取得関数を使う表示へ反映。画面の配置・ラベル変更なし。
- ローカル実装。今回の依頼ではcommit/pushの指定がないため未実行。
