# バトル結果の教材表示・単語リストへの移動

## 変更

- 通常バトルの結果見出しに、遊んだ級・教材とLevelを表示。勝利・敗北のどちらでも現在の教材情報を使用する。
- 既存の補足文を置き換え、教材表示用の大きなカードは追加しない。
- 「今回の問題と結果」の見出し横に「単語リスト」ボタンを配置。現在の級・Levelを保持して一覧を開く。
- 前回の「苦手だけ」などの絞り込みを「すべて」に戻し、選択・自動再生ツールを閉じて開く。学習状態や保存済みの選択内容は変更しない。
- 次へ／再挑戦ボタンの自動フォーカスではスクロールしない。スマホ幅で結果の見出しが隠れることを防ぎ、Enter操作は維持する。他画面のボタンのフォーカス動作は従来どおり。
- 狭い画面では見出しのアイコンと間隔を少し縮め、名前・教材表示の幅を確保する。単語リストボタンのタッチ領域は高さ44px以上。

## 確認

- `npm.cmd run build` 成功。
- `npm.cmd run lint` エラー0件・既存のReact Hook警告1件。
- `scripts/test-result-course-navigation-ui.mjs` で英検5級Level 1の勝利（390px）、英検4級Level 2の敗北（1366px）、英検準1級①Level 3の敗北（820px）を確認。
- 結果を開いた直後の教材名とボタンの可視性、横はみ出しなし、同じ級・Levelの一覧、古い絞り込みとツールの解除、主要ボタンのフォーカス保持、ブラウザー実行エラーなしを検証。
- 自分専用のChrome検証環境を使用。AndroidのOSキーボードを含む実機検証ではない。
- 追加画像・外部フォント・ライブラリなし。問題・HP・採点・モンスター画像・保存形式は変更していない。
